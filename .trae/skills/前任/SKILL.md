# 前任聊天气泡组件

## 功能概述

在页面右下角添加一个小巧的浮动聊天气泡，当用户点击气泡时，展开为全屏或半屏聊天窗口，模拟与前任对话的趣味互动体验。

## 调用时机

- 用户需要在个人主页、趣味展示页、作品集网站中增加一个趣味聊天互动组件时
- 用户明确要求添加"前任"、"聊天气泡"、"怀旧对话"等类似功能时
- 用户想要增加一个隐藏式交互彩蛋，提升页面趣味性与记忆点时

## 实现要点

1. **浮动提示气泡**：固定在页面右下角，带有脉冲呼吸动效与"有新消息"红点提示
2. **点击展开**：点击气泡后，平滑过渡为聊天窗口（半屏或全屏，可根据主题设定）
3. **消息渲染**：左侧为对方消息气泡，右侧为我方消息气泡，带打字机动画延迟
4. **预设剧本**：内置一组"前任风格"预设对话，支持打字机动画、自动回复逻辑
5. **样式统一性**：气泡与聊天窗口颜色继承当前主题 CSS 变量，保持视觉体系一致
6. **可关闭**：聊天窗口右上角提供关闭按钮，关闭后回到气泡迷你态

## 组件清单

- `ExChatBubble.jsx` — 浮动提示气泡（迷你态入口）
- `ExChatWindow.jsx` — 展开后的聊天窗口
- 配套 LESS/CSS 样式定义
